Vela

A browser that collects nothing. Not “less” — nothing.

Download for your computer

What that actually means

  • Two kinds of request out of the box. The pages you navigate to, and one check for a new release. Nothing else — and in development Vela logs anything that tries, so accidental telemetry gets caught while it is being written.
  • Ads and trackers blocked by default, using EasyList and EasyPrivacy compiled into the app. Vela never fetches a filter list at runtime, because that would be a third kind of request.
  • No account, no server, no sync. Everything Vela remembers is one JSON file on your machine, and the settings panel shows you where it is and hands you its contents.
  • Private windows are genuinely private. Their session exists only in memory, and a test in the repository browses in one and proves nothing reaches the disk.
  • One user agent for everyone. No per-install randomisation — that is a fingerprint, not a defence.

An assistant that runs on your machine

The sidebar assistant talks to Ollama on your own computer by default. No key, no account, and nothing typed into it leaves the machine. Install Ollama, pull a model, and the panel works.

You can point it at a hosted service instead, with your own API key. Vela ships without one on purpose: this is a downloadable app, so a key built into it would sit in the bundle for anyone to read, billed to whoever put it there.

The Opera parts

  • A left rail holding workspaces, sidebar tools and your docked sites.
  • Workspaces — named tab groups. Leaving one suspends its tabs, so an idle workspace costs storage for its titles and nothing else.
  • Web panels. Dock any site into the sidebar beside the page. Each one is an ordinary page on the same hardened session a tab uses.
  • Speed Dial, bookmarks, history, downloads and per-site zoom, plus a command palette on Ctrl+K and notes, a calculator and a unit converter in the sidebar.
  • Bang shortcuts — !gh, !yt, !w — resolved on your machine, so they reach the site without a search engine seeing the query first.

Two things it deliberately will not do

No built-in VPN. A browser-branded “free VPN” is somebody else’s server watching all your traffic — the exact arrangement this browser exists to avoid, and it needs infrastructure Vela does not run. Settings takes a proxy or VPN you already trust instead, and routes every session through it.

No sign-in, no sync. An account that carries your data between installs needs a server holding that data. An account is the one thing that turns “a browser on your machine” into “a profile someone else keeps”. Export the settings file and move it yourself.

The first launch will warn you

Vela's builds are not code-signed yet, so your operating system will say it does not recognise them.

Windows: SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.

macOS: Gatekeeper says Vela “cannot be opened because it is from an unidentified developer”. Right-click the app, choose Open, then confirm. Or run xattr -dr com.apple.quarantine /Applications/Vela.app.

Linux: make the AppImage executable with chmod +x Vela-*.AppImage.
