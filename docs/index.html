What it sends

The pages you navigate to, and one plain GET on the GitHub releases feed to see whether there is a newer version. No install identifier, no query string.

Ads and trackers are blocked from EasyList and EasyPrivacy, built into the app. Vela never downloads a filter list, because that would be a third request. Everything it remembers is one JSON file on your disk, and Settings prints the path.

The assistant runs in the app

By default it is a model inside Vela rather than a service. llama.cpp is compiled in, so asking it something never becomes a network request.

No model ships with the installer. You pick one in Settings, it downloads once, and it is checked against its hash before it runs. Ollama works if you already have it, and so does a hosted model with your own key. That last one is the only thing here that talks to anyone.
