Vela

A browser that collects nothing. Not "less" — nothing.

Download for your computer

What that actually means

  • Two kinds of request, ever. The pages you navigate to, and one check for a new release. There is no third.
  • Ads and trackers blocked by default, using EasyList and EasyPrivacy compiled into the app. Vela never fetches a filter list at runtime.
  • No account, no server, no sync. Everything Vela remembers is one JSON file on your machine, and the settings panel shows you where it is.
  • Private windows are genuinely private. Their session exists only in memory, and a test in the repository proves nothing is written to disk.
  • One user agent for everyone. No per-install randomisation — that is a fingerprint, not a defence.

The first launch will warn you

Vela's builds are not code-signed yet, so your operating system will say it does not recognise them.

Windows: SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway.

macOS: Gatekeeper says Vela “cannot be opened because it is from an unidentified developer”. Right-click the app, choose Open, then confirm. Or run xattr -dr com.apple.quarantine /Applications/Vela.app.

Linux: make the AppImage executable with chmod +x Vela-*.AppImage.
